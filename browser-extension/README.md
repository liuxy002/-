# 秋招作战台岗位采集器

这是一个本地 Chrome/Edge 扩展，用于从当前打开的招聘页面提取：

- 公司名称
- 岗位名称
- 城市
- 薪资
- 投递地址
- JD 原文

采集结果会发送到本机的秋招作战台，统一进入“岗位采集箱”。

## 安装

1. 先双击项目根目录的 `启动秋招作战台.cmd`。
2. 打开 Chrome 或 Edge。
3. 地址栏输入 `chrome://extensions` 或 `edge://extensions`。
4. 打开“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择本文件夹：`browser-extension`。
7. 建议把扩展固定到浏览器工具栏。

## 使用

1. 打开一个招聘岗位详情页。
2. 点击浏览器工具栏里的“秋招作战台岗位采集器”。
3. 检查抓取到的公司和岗位信息。
4. 如果 JD 或城市没有抓全，可以手动补充。
5. 点击“发送到岗位采集箱”。
6. 回到秋招作战台，进入“岗位采集箱”确认并加入候选池或投递记录。

## 说明

- 只读取你当前打开的页面，不会批量访问招聘网站。
- 不同招聘网站的页面结构不同，扩展会优先读取页面里的结构化招聘数据和常见 JD 区域。
- 如果某个网站抓取不完整，可以在扩展弹窗中手动补充后发送。
