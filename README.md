# 秋招作战台

第一版个人秋招管理与推荐 Web App。系统完全使用浏览器本地存储，不需要数据库服务，也不会上传投递记录。

## 启动

需要电脑上已安装 Node.js。

双击 `启动秋招作战台.cmd` 或 `start.cmd`。系统会在后台启动本地服务，并自动打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

需要停止时，双击 `停止秋招作战台.cmd` 或 `stop.cmd`。

也可以直接双击 `index.html`，但建议使用本地启动方式，便于后续扩展文件导入和浏览器能力。

## 导入飞书数据

飞书分享链接需要登录，网页不能直接读取登录态后的表格数据。请按以下方式导入：

1. 打开飞书多维表格。
2. 点击右上角「···」。
3. 选择「导出」并下载 CSV。
4. 在本系统「数据导入」页面上传 CSV。
5. 检查字段映射和预览内容。
6. 点击「确认导入」。

系统会识别这些常见字段：公司、岗位、城市、阶段、结果、投递时间、截止时间、测评/笔试时间、面试时间、渠道、简历版本、薪资、行业、公司类型、JD、投递地址、联系人、下一步行动和备注。

## 当前功能

- 秋招总览：投递目标、今日及近 7 天投递统计、响应率、面试率、Offer 率和今日优先事项
- 自定义提醒与日程：首页可新增、编辑和完成个人提醒，也会汇总测评与面试时间，可开启提前 1 天和 2 小时系统通知
- 投递管理：列表、阶段看板、筛选、搜索、投递地址直显、详情和时间线
- 面试记录：面试时间、轮次、面试官、问题和复盘
- 分析复盘：流程转化、地区、岗位、渠道、简历版本和投递趋势
- 推荐中心：粘贴新 JD，根据历史投递结果、偏好和技能画像排序
- 岗位采集箱：从浏览器扩展接收公司、岗位、JD 和投递地址
- 面试复盘：按轮次记录问题、回答、自评、改进项和题库
- 数据导入：飞书 CSV、JSON，支持拖拽、粘贴、备份和导出
- 本地数据：浏览器 localStorage 保存，不需要账号

## 推荐逻辑

第一版使用可解释的内容推荐，不依赖黑盒模型：

- 历史 JD 与候选 JD 的文本相似度
- Offer、面试、测评、响应和无回复使用不同权重
- 目标城市、岗位方向、行业和技能偏好
- JD 信息完整度与新鲜度
- 主动不感兴趣和排除关键词的负向影响

历史样本少于 8 条时，推荐结果以明确偏好为主。随着记录积累，历史结果权重会逐渐提高。

## 数据安全

- 投递数据只保存在当前浏览器的 localStorage 中。
- 清理浏览器缓存、更换浏览器或重装系统可能导致数据丢失。
- 请在「数据导入」页面定期导出 JSON 备份。
- 不要把真实简历手机号、邮箱等敏感信息写入演示数据或公开代码。
